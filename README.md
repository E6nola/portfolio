# Portofolio Sultan Hafidz (S1 Sistem Informasi UDINUS)

Website portofolio statis pribadi Muhammad Sultan Hafidz Herawan. Dibuat dengan HTML, CSS modern, dan JavaScript murni, tanpa dependensi server runtime, sehingga dapat di-host langsung secara gratis dan cepat di GitHub Pages, Vercel, Netlify, atau Cloudflare Pages.

## Struktur Berkas
- `index.html`: Struktur utama portofolio, mencakup DFD Context Diagram, ringkasan keahlian, daftar proyek interaktif, riwayat studi di UDINUS, dan kontak.
- `styles.css`: Styling kustom bertema formal modern (Navy Ink & Warm Paper) dengan aksen emas/biru khas sistem informasi UDINUS. Responsif untuk semua ukuran layar (desktop, tablet, mobile).
- `script.js`: Data proyek komprehensif dari berkas kuliah dan proyek Hermes, sistem filter per kategori, modal/detail gallery gambar, dan interaktivitas diagram DFD.
- `assets/`: Diagram use case, DFD, arsitektur to-be ERP, dan pratinjau proyek.

## Cara Menjalankan Secara Lokal
Cukup buka berkas `index.html` langsung di browser Anda (klik ganda atau buka melalui browser pilihan).

## Cara Publish ke GitHub Pages (Gratis & Online untuk Semua Orang)
1. Buat repository baru di [GitHub](https://github.com/new) bernama `portfolio`.
2. Push branch `main` dari folder ini:
   ```bash
   git push -u origin main
   ```
3. Buka tab **Settings** di repository GitHub Anda > pilih **Pages** (di menu navigasi sebelah kiri).
4. Pada bagian **Build and deployment > Branch**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1-2 menit, website Anda akan langsung aktif dan bisa diakses siapa saja di seluruh dunia melalui tautan:
   `https://sultanhz2006.github.io/portfolio/`
